* memacs_podcastaddict

** Data Source

[[https://podcastaddict.com/][Podcast Addict]] is a popular Android podcatcher app. It can write a
periodic auto-backup of its database to a user-configurable directory
on the device (Settings → Backup / Restore).

Each backup is a ZIP archive named e.g.
=PodcastAddict_autoBackup_20260523_210009.backup= that contains a
SQLite database =podcastAddict.db=. This module reads the most
recently-modified ~*.backup~ file in a directory and emits one
Org-mode entry per *finished* episode (~seen_status = 1~ with a
non-zero ~playbackDate~).

** Options

- ~-d~, ~--backup-dir~ — path to the directory holding the
  ~PodcastAddict_autoBackup_*.backup~ files (required). The newest
  file by modification time is used.
- Standard Memacs options (~-o~, ~-a~, ~-s~, ~-v~, ~--tag~, ...) are
  inherited from the framework.

** Dependencies

- [[https://pypi.org/project/pypandoc/][pypandoc]] (Python wrapper)
- the [[https://pandoc.org/][pandoc]] binary on ~PATH~ (e.g. ~apt install pandoc~,
  ~brew install pandoc~)

Pandoc is used to convert each episode's HTML shownotes into Org-mode
markup faithfully (links, bold, italics, paragraphs, lists, ...).

Install both with:

: uv sync --group podcastaddict

** Automatic appending

The ~:ID:~ property is derived from the episode's database ~_id~ and
~playbackDate~. When invoked with ~-a~ / ~--append~, only entries
whose ID is not already in the output file are appended.

** Output format

The heading carries the finishing time-stamp (local time, converted
from ~playbackDate~), the episode name (linked to its URL if known),
the podcast name (linked to its homepage if known), and the optional
season/episode number ("SxxExx", "Exx", or "Sxx" depending on which
fields PodcastAddict has). The body contains the transcript link
(when present, with format preference srt → html → json → other)
followed by the HTML shownotes converted to Org.

** Example Invocation

: uv run memacs_podcastaddict \
:     --backup-dir /path/to/Android/backups/PodcastAddict \
:     --output /home/user/orgmode/memacs/podcastaddict.org_archive \
:     --append
