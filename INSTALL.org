* How to install and set up Memacs

** *Prerequisites*

- *Python 3.9 or newer*
- [[https://docs.astral.sh/uv/][uv]] (recommended) for managing the Python environment and dependencies.
  Install uv with the official one-liner:
  : curl -LsSf https://astral.sh/uv/install.sh | sh
  See the [[https://docs.astral.sh/uv/getting-started/installation/][uv install docs]] for other platforms.

** *Obtain and install Memacs*

There are two recommended workflows depending on whether you just want
to /use/ Memacs or also /hack on/ it.

*** As a tool (just run the modules)

If Memacs is published to PyPI, you can install all the ~memacs_*~
console scripts globally with uv:

: uv tool install memacs

This makes commands like ~memacs_rss~, ~memacs_csv~, ~memacs_git~,
... available on your ~PATH~ without activating any virtualenv. Update
later with:

: uv tool upgrade memacs

Note that ~uv tool install~ only pulls Memacs' core dependencies. Each
module may need additional packages (see ~pyproject.toml~ →
~[dependency-groups]~). To include them:

: uv tool install memacs --with feedparser --with icalendar

*** From a git checkout (recommended for everyone right now)

This is the path most users will want today, and the only path for
contributors.

: git clone https://github.com/novoid/Memacs.git
: cd Memacs
: uv sync --all-groups

That single ~uv sync~ command creates ~.venv/~, resolves all
dependencies (incl. every module's optional deps and dev tools), and
installs Memacs itself in editable mode. Run any module via:

: uv run memacs_rss --help
: uv run memacs_csv --help

To install only what you need instead of everything, pick groups:

: uv sync --group rss --group ical

Available dependency groups: ~gps~, ~rss~, ~ical~, ~lastfm~,
~battery~, ~twitter~, ~photos~, ~contacts~, ~podcastaddict~, ~dev~.

The ~podcastaddict~ module additionally needs the [[https://pandoc.org/][pandoc]] binary on
~PATH~ (e.g. ~apt install pandoc~ or ~brew install pandoc~) for the
HTML-to-Org conversion of shownotes.

*** Updating

- ~uv tool upgrade memacs~ for tool installs.
- ~git pull && uv sync --all-groups~ for git checkouts.

** *Choose* the *modules* you want to use

- Read the files in the ~docs~ folder.
- Each module is launched via its ~memacs_<name>~ console script
  (e.g., ~memacs_rss~). If you cloned the repo, you can also still
  invoke the ~.py~ files directly from ~bin/~ under ~uv run~.

** *Set up one module* after another

- Please read [[https://github.com/novoid/Memacs/blob/master/docs/FAQs_and_Best_Practices.org][docs/FAQs_and_Best_Practices.org]]
  - it contains many tips and tricks on how to meet your
    requirements and on how to choose a reasonable setup.
- Start the module of your choice with ~--help~ to see its options:
  : uv run memacs_svn --help
  Each module has some general arguments and module-specific arguments.
- You probably want to *develop and test a module invocation* on the
  command line, and when it works:
- Set up a periodical invocation
  - read the [[https://github.com/novoid/Memacs/blob/master/docs/FAQs_and_Best_Practices.org#invocation][Invocation]] section of [[https://github.com/novoid/Memacs/blob/master/docs/FAQs_and_Best_Practices.org][docs/FAQs_and_Best_Practices.org]].
